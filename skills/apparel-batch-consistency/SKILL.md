# Apparel Batch Consistency

## Core principle

Consistency across the set is more important than aggressive optimization of any single image. Establish one approved master treatment, then apply it consistently.

## Workflow

1. Inventory all input images and note dimensions, aspect ratios, garment types, colors, and backgrounds.
2. Select one representative image and create a proposed treatment.
3. Get approval when the look is subjective or materially changes color/brightness.
4. Apply the same background, crop logic, tonal treatment, shadow style, and export settings to the set.
5. Use local masks where different garment colors or materials need protection.
6. Never force identical exposure values if doing so damages the actual garment color; consistency must not override product accuracy.
7. Export files with stable, descriptive names and keep originals untouched.
8. Review a contact sheet or all outputs together to detect drift.

## Export controls

Confirm:
- Platform and target dimensions.
- Aspect ratio and safe margins.
- JPEG/PNG/WebP choice and quality.
- Transparent vs solid background.
- Color profile when specified.
- Naming convention and destination folder.

Do not invent platform requirements. If the user does not specify a platform, ask only if the choice materially affects the output; otherwise provide a sensible general web export and state the dimensions used.

## Final QA

Check every file for clipping, color shifts, background inconsistencies, halos, sharpening differences, and accidental changes to garment construction. Do not report batch completion until all outputs are accounted for.
